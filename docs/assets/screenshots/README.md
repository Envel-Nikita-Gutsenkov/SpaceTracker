# Screenshots

The PNGs in this folder render the **Screenshots** section of the root
`README.md`. They are currently on-brand **placeholder cards**, not real
captures.

Replace each file (same name, same 16:9 aspect ratio) with an actual screenshot
of the matching view:

| File | View to capture |
|---|---|
| `hero.png` | Live Earth globe with the tracked satellite catalogue |
| `satellites.png` | Global constellation view (category points, labels, orbits) |
| `spacecraft.png` | A spacecraft close-up (e.g. the ISS or a NASA model) |
| `planets.png` | A planet detail view (e.g. Saturn with its rings) |
| `dwarf_moons.png` | The dwarf planets & moons catalogue |
| `sidebar.png` | The sidebar with filters and search |
| `info_panel.png` | The satellite info panel |

Tips: capture at ~1600×900, keep the app in its dark theme, and optimise the
PNGs before committing so the repo stays light.

A capture of the running app embeds its textured content, so a real screenshot
is a **derivative work** of those assets and carries their licenses (e.g. the
CC BY-SA planet/moon maps stay CC BY-SA). The current placeholder cards use no
third-party imagery. See [`../../THIRD-PARTY-NOTICES.md`](../../THIRD-PARTY-NOTICES.md).
